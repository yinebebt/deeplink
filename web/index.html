Short links that open the right app.

deeplink is an open-source Go library and self-hostable server for deep links.

  • Smart deep links: one URL opens your iOS or Android app, with store or web fallback.
  • Rich social previews with Open Graph, Twitter Card, and fediverse tags.
  • Click analytics by platform, referrer, and day, with no third-party tracker.
  • Built for AI agents: an MCP server to create, list, and inspect links.
  • API keys that rotate without a restart, with a grace period for clients.
  • SQLite, Redis, or in-memory storage, with link expiry.
